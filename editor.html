      Conexión con GitHub

      Cómo sacar el token
      1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      2. Nombre: editor mesas. Expiración: la que quieras.
      3. Repository access: Only select repositories → escoge tu repositorio de mesas.
      4. Permissions → Repository permissions → Contents: Read and write.
      5. Generate token, cópialo y pégalo aquí.
